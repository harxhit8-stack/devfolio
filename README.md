# Harshit - Developer Portfolio

A modern, responsive personal developer portfolio built with HTML and CSS. This website showcases my development journey, skills, and projects through a clean and user-friendly interface.

The portfolio uses semantic HTML, Flexbox, CSS Grid, responsive media queries, and a consistent colour and typography system to provide a smooth experience across desktop and mobile devices.

## Features

- Responsive design for mobile and desktop
- Semantic HTML structure
- Flexbox navigation
- CSS Grid project layout
- About section
- Project showcase
- Contact links
- GitHub Pages deployment
